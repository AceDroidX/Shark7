# 今天播吗 / 今天播什么 功能设计计划

## 目标

新增一个面向 QQ 机器人的主播日程查询功能。

当用户输入包含以下关键词时：

- `今天播吗`
- `今天播什么`

系统需要返回：

- 主播今天是否播
- 主播今天播什么
- 主播今天与未来 7 天的日程

这里的“日程”不只包含直播，也包括：

- 联动
- 录音 / 录制
- 活动
- 出行
- 投稿 / 发布
- 其他公开提到的安排

## 本阶段约束

- 未来日程窗口固定为 `7 天`
- 当前的数据源先从微博入手
- 回答需要提供信息来源
- 数据源可能包含：
  - 概率性表达
  - 模糊时间
  - 时间范围
  - 其他不确定性表达

## 设计方案
每次微博更新时触发日程更新任务，将当前已有的日程信息和新的微博内容一起发送给 LLM 进行处理，LLM 需要从中提取出日程信息并进行去重、合并等处理，最终得到一个更新后的日程表。
